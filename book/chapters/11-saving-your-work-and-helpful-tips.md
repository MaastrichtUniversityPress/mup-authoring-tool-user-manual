# Saving Your Work and Helpful Tools

## Automatic Saving

Your title, text, chapter order, references, and added images are saved on your computer as you work. You do not need to press a Save button. The desktop app keeps this draft in its own local data folder. If you use the browser version, the draft is saved in that browser's local storage instead; the two copies are separate.

**Local saving is not a GitHub backup.** Your unpublished changes are available only in that local copy. Replacing the draft through New Book, opening a GitHub book, or switching versions replaces it. Removing the desktop app's saved data, or clearing site data in the browser version, can also remove the draft.

## Preserve Work Before Switching Books or Versions

1. Publish a version if your work is ready and appropriate to upload, then confirm the build succeeded
2. If you cannot publish, open the Introduction and each chapter you want to keep. Copy the writing-area text into separate text files, and use **"••• → Download .md"** if you also want the generated Markdown
3. Keep the original image files, bibliography details, book title, and chapter order separately. Save any bibliography writing-area text too
4. Check that you have the copies you need before replacing or loading a book

These separate files are a partial backup. To restore unpublished work from them, create or open the intended book, paste the saved writing-area text into the appropriate sections, add the original images again, and recreate the reference entries. If you only kept the generated Markdown, its heading and formatting marks may need adjustment when pasted into the writing area. Check the Live preview, image paths, and citations afterwards. There is no full-book file import or one-click restore in the current interface.

## The More Actions Menu

Click **"•••"** in the editor toolbar to find these tools:

| Tool | What it does |
|------|--------------|
| **Copy Markdown** | Copies the generated Markdown for the open section |
| **Download .md** | Downloads the open section's Markdown text |
| **Load Example** | Replaces the open section's text with an example |
| **Clear chapter** | Clears the open section's writing area |

**Be careful:** Load Example and Clear chapter change the current content immediately and save the change. Use a spare chapter or keep a copy before trying them.

**About downloads:** Download .md exports one section. It is not a complete book backup and does not package image files or all book settings. There is no full-book import button in the current interface.
