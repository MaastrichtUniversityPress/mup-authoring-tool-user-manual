## Getting Help

If you have questions or run into issues:

1. **Review this manual:** Check the relevant section above
2. **Check the `FAQ`:** Your question might be answered there
3. **Follow the `First Publishing Workflow`:** Work through the steps from a new book to a published version
4. **Click "?":** Open the guided tour of the app
5. **Contact your administrator:** Include the screen, action, and error message for technical issues

For a publishing problem, include the book and version name, the messages under **"What happened"** and **"What to do next"**, and relevant **"Technical details"**. Do not include passwords or GitHub login codes.

## Quick Cheat Sheet

| What you want | What to type or click |
|---------------|----------------------|
| Resume the local draft | **Resume Book** on the home page |
| Bold text | `**bold**` or **B** |
| Italic text | `*italic*` or **I** |
| Bullet point | `- Item 1` or **• List** |
| Numbered list | `1. First` or **1. List** |
| Quote | `> A famous quote` or **❝** |
| Automatic heading | A short standalone line |
| Keep a short line as text | Start it with `\` |
| Link | `[link text](https://example.com)` or **Link** |
| Image | **＋ Add image**, after entering alt text |
| Citation | Choose a source and click **Insert Citation** |
| Check the book | **Readiness Check** |
| Publish a version | **Publish**, enter a unique name, then **Publish this version** |
| Share an older version | **Published Versions → Copy link** |
