# Working with Existing Books

## Loading Books from GitHub

1. Sign in with GitHub
2. Use **"Close Book"** to return to the home page if a book is open
3. In **"GitHub Books"**, click **"Refresh"**
4. Find the book and click **"Edit"**

The list contains approved repositories in the configured organisation that your account can access and that are detected as TeachBooks projects. It does not list all repositories in your personal GitHub account. Each book also has **"Repo"** to open its GitHub repository and **"Published"** to open its published site. For a specific version link, use Published Versions inside the book.

**Book missing?** Check that you are signed in with the correct account, then click **"Refresh"**. If it still does not appear, ask your administrator to check your access, the GitHub App's selected repositories, and the book's TeachBooks structure.

Opening a GitHub book replaces the current local working copy, even when you open the same book again. Preserve unpublished changes before clicking **"Edit"**. The New Book replacement confirmation does not protect this action.

## Editing Chapters

1. Click a chapter card
2. Edit its title and content
3. Check the Live preview
4. Click **"← Chapters"** to return to the chapter list
5. Publish a new named version when you are ready to share your changes

## Closing a Book

**"Close Book"** returns you to the home page. Click **"Resume Book"** to reopen the current local draft. Restarting the desktop app also opens the home page, with the saved draft available through **"Resume Book"**. Closing does not delete the GitHub repository or its published versions, and it does not publish your latest edits.
