# Working with Published Versions

## Find and Share a Version

1. Open your GitHub-connected book
2. Find **"Published Versions"** below the book overview
3. Click **"Refresh"** to update the list
4. Use **"Open"** to view a version or **"Copy link"** to share it

The cards show the version name and publication information. **"Latest"** identifies the most recent entry in the list. **"Editing"** identifies the version currently loaded for editing.

## Continue from an Earlier Version

1. Preserve any unpublished changes in your current book first
2. Click **"Use for editing"** beside the version you want
3. The app loads that version's content into the editor
4. Make your changes
5. Publish with a **new version name**, such as **"second draft"**

**Be careful:** Switching versions replaces the current local working copy. It does not merge your unpublished edits into the selected version.

Editing a loaded version does not change its published snapshot. Publishing with a new name creates another version; earlier version links remain available.
