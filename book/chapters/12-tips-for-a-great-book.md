
# Tips for Great Books

## Formatting Tips

- ✅ **Use bold sparingly:** For emphasis on important terms only
- ✅ **Use italics for titles:** Great for book titles or emphasis
- ✅ **Keep quotes relevant:** Only quote when it adds value
- ✅ **Space out content:** Use paragraph breaks to improve readability
- ✅ **Review images and references:** Check descriptions, citations, and links

## Publishing Tips

- ✅ **Run Readiness Check:** Fix blockers before publishing
- ✅ **Name versions clearly:** Use names readers will recognize
- ✅ **Proofread everything:** Check spelling and grammar carefully
- ✅ **Open the published book:** Confirm the online result before sharing
- ✅ **Share the right link:** Use the link for the version you want readers to see

---

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Enter` twice | Separate paragraphs in the writing area |
| `Ctrl+B` | Apply or remove bold formatting on selected text |
| `Ctrl+I` | Apply or remove italic formatting on selected text |
| `Ctrl+C` | Copy selected text |
| `Ctrl+V` | Paste text |
| `Enter` in the version-name dialog | Submit the version name |
| `Esc` in the version-name dialog | Cancel the dialog |

The editor's bold and italic shortcuts also accept `Cmd` instead of `Ctrl` when using a browser on a Mac.
