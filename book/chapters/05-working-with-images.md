# Working with Images
## Adding Images
1. Place your cursor where you want the image in the writing area
2. Enter a description in "Image alt text, e.g. Diagram of programming languages"
3. Click "＋ Add image"
4. Select an image file from your computer
5. Check that the image appears in the Live preview
The app inserts the image text and saves the image with the current book. It uploads saved images when you publish. If you leave the description blank, the app uses the filename without its extension

## Image Tips
- Good formats: PNG, JPG, GIF
- Keep file sizes reasonable: Large images take more space and slow down loading
- Always add descriptions: Explain what the image shows, especially for readers who cannot see it
- Keep original files: A downloaded chapter .md file does not include the image files
- Use the image button: Typing a local image path by itself does not save the actual image with your book
If an image is missing, check its path and add the original image again if needed. Update or remove the old broken image text, then run the Readiness Check.
