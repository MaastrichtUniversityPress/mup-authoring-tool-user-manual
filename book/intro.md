# MUP Authoring Tool - User Manual
## Welcome!
This manual explains how to write, check, and publish a book using simple plain text. You do not need to write code.
The desktop app is called **MUP Authoring**. Inside the app, you'll see **MUP Authoring Tool** at the top of the screen.
This manual covers the Windows desktop app.
Want to follow a complete example? See the *First Publishing Workflow* chapter. For quick answers, see the *Frequently Asked Questions* chapter.
